# Alexandra Caldwell for Ward 1 — campaign website

Static site: plain HTML, CSS and images, no build step. Edit a page, commit, and GitHub Pages republishes it.

- `index.html` — homepage
- `meet.html`, `priorities.html`, `neighbourhoods.html`, `involved.html`, `vote.html`, `donate.html`, `contact.html`
- `images/` — photos, logo, lawn sign and lighthouse marks

Forms submit through FormSubmit to the campaign Gmail. The first submission after going live triggers a one-time activation email to that inbox.
